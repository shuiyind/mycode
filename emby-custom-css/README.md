# 🎬 Emby Custom CSS

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Emby Version](https://img.shields.io/badge/Emby-4.7%2B-green.svg)

本仓库提供一套针对 Emby 深度定制的 CSS 优化方案，侧重于中文字体美化与播放字幕增强。

---

## ✨ 核心特性

* **🖋️ 字体重塑**：采用 **霞鹜文楷 (LXGW WenKai)** 作为首选字体，辅以 `Noto Serif SC`，显著提升阅读质感。
* **💬 字幕增强**：针对播放器字幕进行重绘，支持全屏响应式缩放，并增加黑色描边防止背景干扰。
* **📐 居中排版**：强制卡片标题、项目名称及页面标题居中，并实现多行文本自动截断（最多3行）。
* **📱 响应式适配**：专门针对移动端（768px以下）优化字幕字体大小，确保跨端体验一致。

## 🚀 安装步骤

1.  **获取代码**：打开目录下的 [`emby-custom-css.css`](./emby-custom-css.css) 并复制全文。
2.  **进入后台**：登录 Emby 控制台，点击 **设置 -> 通用** (General)。
3.  **应用样式**：找到页面下方的 **“自定义 CSS”** 文本框，粘贴代码并保存。
4.  **即时生效**：刷新浏览器或重新打开 App 即可看到优化后的效果。

## 🛠️ 代码结构说明
* `--- 1. 字体声明 ---`: 引入国内加速的文楷字体及 Google Fonts。
* `--- 2. 视频字幕优化 ---`: 核心字幕样式，包含响应式字号及描边补强。
* `--- 3. 界面标题排版 ---`: 修正居中显示与多行截断逻辑。
* `--- 4. 全局字体替换 ---`: 强制全局 UI 应用文楷字体。
