# Emby Custom CSS

这是一个轻量级的 Emby 样式增强方案，专注于 **霞鹜文楷** 字体重塑与全链路自适应布局。

## 特性

- **字体重塑**：优先调用 `LXGW WenKai`（霞鹜文楷），并结合 `Noto Serif SC` 确保阅读质感。
- **全链路自适应**：界面文字与视频字幕均采用 `calc()` 动态缩放，自动适配移动端与桌面大屏，优化后的参数有效防止导航栏遮挡。
- **字幕增强**：动态字号配合高对比度描边算法，提升各种背景下的文字辨识度。
- **排版优化**：卡片标题与项目名称强制居中，支持最多 3 行文本自动截断。

## 安装

1. 复制 `emby-custom-css.css` 全文。
2. 登录 Emby 后台：**设置** > **通用** > **自定义 CSS**。
3. 粘贴并保存。
