# 🎬 Emby Custom CSS

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Emby Version](https://img.shields.io/badge/Emby-4.7%2B-green.svg)

本仓库提供一套深度优化的 Emby 媒体服务器自定义 CSS 方案。

---

## ✨ 核心优化

* **🖋️ 字体重塑**：全局引入 **霞鹜文楷 (LXGW WenKai)**，针对中文显示深度优化。
* **📺 沉浸式 UI**：移除底部 Logo 及版本号，让界面视觉焦点回归媒体内容。
* **📱 全屏响应式**：优化不同设备下的布局表现，适配移动端与网页端。
* **🧩 细节打磨**：对海报卡片、控制按钮增加圆角（12px），观感更柔和现代。

## 🚀 安装步骤

1.  **获取代码**：打开本目录下的 [`emby-custom-css.css`](./emby-custom-css.css) 并复制全文。
2.  **进入后台**：登录 Emby 控制台，点击左侧菜单的 **“通用” (General)**。
3.  **粘贴保存**：在页面下方的 **“自定义 CSS”** 文本框中粘贴代码，点击保存。

* **CDN 加速**：代码中已配置 `jsDelivr` 加速字体加载，国内访问依然流畅。
* **按需修改**：你可以通过搜索 `--- 1. 字体声明 ---` 等注释内容，快速定位并修改你想要自定义的部分。
