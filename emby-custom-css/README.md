# Emby Custom CSS

这是一个轻量级的 Emby 样式增强方案，专注于 **霞鹜文楷** 字体重塑与全链路自适应布局。

## 特性

- **字体重塑**：优先调用 `LXGW WenKai`（霞鹜文楷），并使用 `Noto Serif SC` 兜底，提升中文阅读质感。
- **全链路自适应**：界面文字与视频字幕均采用 `calc()` 混合逻辑，根据屏幕宽度动态缩放，适配手机、平板及 4K 大屏。
- **字幕增强**：优化动态字号与高对比度黑色描边，确保在各种视频背景下清晰易读。
- **排版优化**：卡片标题与项目名称强制居中，支持最多 3 行文本截断。

## 使用方法

1. 复制 `emby-custom-css.css` 文件中的全部内容。
2. 登录 Emby 管理后台：**设置** > **通用**。
3. 粘贴至 **自定义 CSS** 输入框并保存。

## 兼容性

- **Emby Server**: 4.7+
- **浏览器**: 主流现代浏览器（Chrome, Edge, Safari, Firefox）
