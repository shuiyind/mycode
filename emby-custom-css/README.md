# 🎬 Emby Custom CSS

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Emby Version](https://img.shields.io/badge/Emby-4.7%2B-green.svg)

本仓库提供一套针对 Emby 深度定制的 CSS 优化方案，侧重于中文字体美化与播放字幕增强。

---

## ✨ 核心特性

* **🖋️ 字体重塑**：完全采用 **霞鹜文楷 (LXGW WenKai)** 作为核心字体，内置国内 CDN 加速，提供极佳的中文阅读质感。
* **💬 字幕增强**：对播放器字幕进行重排，支持响应式字号、加粗及黑色描边，确保在各种背景下清晰易读。
* **📐 居中排版**：强制项目名称、标题及卡片文字居中显示，视觉焦点更集中。
* **✂️ 多行截断**：优化标题排版，支持最多 3 行文本显示，超出部分自动省略，防止界面错位。
* **📱 全屏适配**：针对移动端（768px 以下）独立优化字幕比例，确保跨端体验一致。

## 🚀 安装步骤

1.  **获取代码**：打开目录下的 [`emby-custom-css.css`](./emby-custom-css.css) 并**复制全文**。
2.  **进入后台**：登录 Emby 控制台，点击左侧菜单的 **“通用” (General)**。
3.  **粘贴保存**：在页面下方的 **“自定义 CSS”** 文本框中粘贴代码，保存即可。

## 🛠️ 代码结构说明
* `--- 1. 字体声明 ---`: 远程加载国内加速的霞鹜文楷字体。
* `--- 2. 视频字幕优化 ---`: 处理字幕渲染、响应式大小及描边补强。
* `--- 3. 界面标题排版 ---`: 实现标题居中、多行截断及宽度自适应。
* `--- 4. 全局字体替换 ---`: 强制全局 UI 应用文楷字体并微调按钮样式。
