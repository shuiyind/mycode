# 🎬 Emby Custom CSS

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Emby Version](https://img.shields.io/badge/Emby-4.7%2B-green.svg)

针对 Emby 深度定制的 CSS 优化方案，侧重于中文字体重塑与播放字幕增强。

---

## ✨ 核心特性

* **🖋️ 字体重塑**：采用 **霞鹜文楷 (LXGW WenKai)** 优先，并结合 `Noto Serif SC` 兜底，提供极佳的中文阅读质写感。
* **💬 字幕增强**：对播放器字幕进行重排，支持响应式字号、黑色描边处理，确保在各种视频背景下清晰易读。
* **📐 居中排版**：强制项目名称、标题及卡片文字居中显示，视觉焦点更集中。
* **✂️ 多行截断**：优化标题排版，支持最多 3 行文本显示，超出部分自动省略，防止界面错位。
* **📱 全屏适配**：针对移动端独立优化字幕比例，确保跨端体验一致。

## 🚀 安装步骤

1.  **获取代码**：复制 [`emby-custom-css.css`](./emby-custom-css.css) 全文。
2.  **粘贴保存**：登录控制台 -> **设置 -> 通用** -> 粘贴至 **自定义 CSS** 框。
