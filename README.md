| 目录 | 说明 | 版本控制 |
| --- | --- | --- |
| `touhou-little-maid-command-processor/` | Minecraft 1.21.1 女仆指令处理器模组 (NeoForge) | 独立 Git 仓库,远程为同名 GitHub 仓库 |
| `HeroSigil/` | Minecraft 英雄纹章模组 (NeoForge) | 独立 Git 仓库,远程为 `shuiyind/HeroSigil` |
| `reader-next/` | 阅读应用 (Rust + 前端) | 独立 Git 仓库,远程为 `myfork` |
| `lm-studio-monitor/` | LM Studio 监控仪表盘 (纯 HTML/JS) | 由本仓库管理 |
| `local-llm-test/` | 本地大模型测试脚本 (Python) | 由本仓库管理 |
| `mac-ai-research/` | Mac 本地大模型对比研究 (Python) | 由本仓库管理 |
| `PermanentBuffs/` | 预留(当前仅 Gradle 缓存) | - |
