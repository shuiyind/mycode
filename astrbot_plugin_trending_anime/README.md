# 全网热搜与动漫按需查询工具

一个基于 AstrBot 框架的 Python 插件，通过大模型的 Tool Calling（函数调用）能力，实现按需获取实时热搜及动漫剧集信息。

## 功能特性

- 实时获取微博、知乎、百度、抖音等平台热搜
- 查询动漫信息（中文名、开播日期、总集数、评分、摘要）
- 支持自定义动漫API接口
- 数据预清洗，优化AI读取效率
- 安全配置管理，避免硬编码敏感信息
- **智能缓存机制**：热搜数据缓存10分钟，动漫信息缓存1小时，减少API调用频率
- **请求频率限制**：防止过于频繁的API请求，避免被封禁
- **超时保护**：设置30秒超时时间，防止响应过慢

## 安装方法

1. 将此插件目录复制到AstrBot的`data/plugins`目录下
2. 重启AstrBot以加载插件
3. 在插件管理界面配置相关参数

## 配置说明

### 必需配置
- **alapi_token**: 用于访问 ALAPI (alapi.cn) 获取热搜数据。请前往 alapi.cn 申请免费Token。

### 可选配置
- **custom_anime_api**: 用户私有的动漫API地址（如未设置将使用Bangumi公共API）

## API申请指南

### ALAPI Token申请
1. 访问 [ALAPI官网](https://alapi.cn/)
2. 注册账号并登录
3. 在控制台找到热搜相关API
4. 获取您的专属Token并填入插件配置

## 使用说明

插件会自动注册以下工具供AI调用：
- `get_trending_news(platform)`: 获取指定平台的热搜信息
- `search_anime_info(keyword)`: 搜索动漫信息

## 依赖

- httpx >= 0.25.0

## 缓存与访问策略

- **热搜数据**：缓存10分钟（600秒），因为热搜内容变化较快
- **动漫信息**：缓存1小时（3600秒），因为动漫信息相对稳定
- **请求频率限制**：最小请求间隔1秒，防止过于频繁的API调用
- **超时设置**：所有API请求设置30秒超时，防止长时间等待

## 开发

此插件遵循AstrBot插件开发规范，使用异步网络请求库httpx进行API调用，并实现了数据预清洗功能。
